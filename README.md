# Phys375SonificationProject

This has been my favorite project I've ever done. A whole lot of work has been poured into it.

The data I'm sonifying comes from [here](https://www.kaggle.com/datasets/fedesoriano/traffic-prediction-dataset)

[This](https://youtu.be/Sz5CxvoWtP0) is a quick demo of the the interface. I've recorded a longer video but haven't gotten around to editing it yet.

Max/MSP has the ability to turn MaxPatchers into .exe files! Unfortunately, with all the dependencies, the file is gigantic. Here is a link to the .zip file that lets you run it on your own device without
Max/MSP. This version isn't the most up-to-date version of the code and is lacking a few features (like mouse-controlled volume controls in presenter mode). But it's a start! Will try to find a better way to 
share this massive file. [Here's the google drive link](https://drive.google.com/file/d/1NCz_XRNUD6zv-DPuUOKgzABxPaCB_Sgx/view?usp=drive_link)
